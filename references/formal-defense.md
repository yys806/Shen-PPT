# 正式答辩模板规格（Formal Defense）

> 场景：**夏令营/正式答辩/自我介绍**（北大/清华/同济三校变体）。模板来源：`templates/formal-defense/标准答辩模板-北大.pptx`（用户提供，2026-08-14 拷贝）。
> 画布 1280×720，5 页结构：封面 / 目录 / 章节页 / 内容页 / 结束页。

## 三校变体（颜色 + 校徽替换）

| 学校 | 校色（反转突出色） | 校徽素材位置 |
|---|---|---|
| 北大 | **北大红 #9A0001** | `assets/schools/pku/`（圆形校徽.png + 横版校徽.png） |
| 清华 | **清华紫 #660874** | `assets/schools/tsinghua/`（圆形校徽.png + 横版校徽.png） |
| 同济 | **同济蓝 #0055A4** | `assets/schools/tongji/`（圆形校徽.png + 横版校徽.png） |

- 圆形校徽：官方 PNG（urongda 1024px，透明底）
- 横版校徽：**圆形官方校徽 + 书法体校名 + 英文名** 合成（`scripts/make_school_logos.py` 可重新生成；北大毛体/同济舒同体用 FZSTK 方正舒体近似、清华用 STLITI 华文隶书近似）
- 三校变体 = 替换校徽 + 把全部校色（导航条反转色/封面强调色）换成对应学校色

## 页面结构与规格

### 封面（第1页）
- 大标题：微软雅黑（标题）40pt
- 副标题：微软雅黑 20pt
- 汇报人：微软雅黑 18pt（"汇报人：XXX"）+ 日期

### 目录（第2页）
- 条目 "01. XXXX / 02. XXXX / 03. XXXX" 形式

### 章节页（第3页）
- "PART XXX"：微软雅黑 40pt
- 章节标题：微软雅黑 48pt

### 内容页（第4页）⭐ 核心版式
**顶部导航条**（y=0~82，全宽）：
- 最左侧：**校徽组** [14,14 187x52]（圆形校徽 + 横版带名字校徽）
- 右侧 4 个章节标签依次展开（间隔约 255px，竖线分隔）：
  - 学业竞赛 [221,0 255x82] / 科研经历 [479,-1 262x80] / 项目实践 [743,-1 273x82] / 学习规划 [1021,-1 258x82]
  - **当前章节标签 = 校色填充 + 白字（反转突出）**；其余 = 白底黑字
  - 讲到哪部分，哪部分就反转（用户明确要求的效果）
- 正文区：左侧大图 + 多栏目（基本信息/竞赛荣誉/核心课程 + 图片）

### 结束页（第5页）
- "感谢老师聆听与指导" + 学校学院夏令营名 + 汇报人

## 字体规格（用户明确）

| 用途 | 字体 |

| **标题类**（大标题/副标题/章节/标签） | **微软雅黑**（保持模板现状） |
